# KANTİN-KAFETERYA

KANTİN-KAFETERYA

İşletmecinin satış yapacağı ürünlerden Çay Su, Poğaça ve Simitin fiyatları idaremizce belirlenmektedir. Diğer ürünlerde piyasa fiyatlarında satış yapılmaktadır. Piyasa Fiyatının üzerinde satış yapıldığı tespit edildiğinde İDARE’ce müdahale edilecektir.
