# 11 Nisan 2026 Tarihli "Değişim Programları Yabancı Dil Sınavı"

11 Nisan 2026 Tarihli "Değişim Programları Yabancı Dil Sınavı"

Sınav Bilgileri:

● Değişim Programları Yabancı Dil Sınavı, **11 Nisan 2026** **Cumartesi** günü saat **10:00’da** Bursa Teknik Üniversitesi Yıldırım Bayezid Yerleşkesinde Yabancı Diller Yüksekokulunda gerçekleştirilecektir.

● Değişim Programları Yabancı Dil Sınavı tek oturum olarak gerçekleştirilecektir. Sınav, **çoktan seçmeli 80** **sorudan** oluşmaktadır. Sınav süresi **120 dakika** dır.

● Erasmus+ Öğrenci Öğrenim ve Staj Hareketliliği başvurusu tamamlanmış olan **TÜM** adayların **bu** **sınavına katılmaları zorunludur**

(ilan ile ilgili ayrıntılı bilgi için **TIKLAYINIZ**.).

**Dil sınavı için ayrıca bir başvuruya gerek yoktur.**

● Değişim Programları Yabancı Dil Sınavına ilişkin ayrıntılı bilgi aşağıdaki tabloda yer almaktadır:

| | | |
| | | |
| Beceri Adı | Soru Tipi | Soru Sayısı |
| Diyalog Dinleme (Listening to a dialogue) | Çoktan Seçmeli | 5 |
| Ders veya Konu Anlatımı Dinleme (Listening to a lecture) | Çoktan Seçmeli | 10 |
| Dil Bilgisi (Grammar) | Çoktan Seçmeli | 14 |
| Kelime Bilgisi (Vocabulary) | Çoktan Seçmeli | 16 |
| Diyalog Tamamlama (Dialogue Completion) | Çoktan Seçmeli | 10 |
| Paragraf Tamamlama (Paragraph Completion) | Çoktan Seçmeli | 5 |
| Paragrafta Okuduğunu Anlama (Paragraph Comprehension) | Çoktan Seçmeli | 20 |

Değişim Programları Yabancı Dil Sınavı Kılavuzuna ve örnek sorulara ulaşmak için TIKLAYINIZ

● Lütfen sınav günü yanınıza **T.C. kimlik kartı**, BTÜ öğrenci kimlik kartı **(Öğrenci kimlik kartı olmayan öğrenciler e-Devlet üzerinden aldıkları öğrenci belgesi ile sınava girebilir)**, su, kalem, silgi, kalemtıraş vb. eşyalarınızı almayı unutmayınız.

● Kimlik kontrolü ve sınav yerleşimi için adayların sınav oturumlarının başlama saatlerinden en geç 30 dakika önce sınav olacakları derslikte hazır bulunmaları gerekmektedir.

● Sınav, **55-69 puan adayların B1 seviyesinde; 70 ve üzeri puan ise adayların B2 seviyesinde dil yeterliliğine sahip olduğunu göstermektedir.** Adayların yanlış cevaplarının sayısı doğru cevaplarını etkilemeyecektir.

●  Sınava giren adaylar, sınav sonuçlarını Bursa Teknik Üniversitesi Yabancı Diller Yüksekokulu’nun resmî web sayfasındaki “BTÜYDS” menüsünün altındaki “ **Sonuç Açıklama Sistemi** **”** sekmesinden veya duyurular bölümünde yayınlanacak ilgili duyurudan öğrenebilirler.

**Not:** Aday listesi ve sınav yeri (derslik) bilgileri 9 Nisan Perşembe günü Yabancı Diller Yüksekokulumuzun resmî web sayfasından duyurulacaktır.Lütfen web sitemizdeki duyuruları düzenli olarak takip ediniz
