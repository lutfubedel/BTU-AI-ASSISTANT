# Ekampus Support

Ekampus Support

For assistance with distance education systems, please send an e-mail to ekampus@btu.edu.tr.

Please pay attention to the following points when sending an e-mail:

1\. Do not write your entire problem in the “Subject” section.

2\. In the “Subject” section, please write a short statement directly related to your problem.

For example: Ekampus-Login Problem, Ekampus-Course List Error, Email-Password, etc.

3.Specify your student number
